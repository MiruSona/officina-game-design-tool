## 0. 한 장 요약

**긴 근거 글 안에 바뀐 토막 하나가 묻히면 NLI 가 「무관」으로 흘린다.** 그래서 근거를 토막으로 잘라
**토막 하나 ↔ 주장 통째**를 토막마다 다 묻고, 원래 꼴 답과 합쳐 **가장 큰 b(반대 확률)** 를 그 짝의 b 로 쓴다.

## 2. 자르기 규칙 (근거만)

1. **머리를 뗀다.** 맨 앞의 `[절 : …]` · `[줄 머리 : …]` · `[칸 머리 : …]` 하나를 뗀다 (첫 `]` 까지). 머리는 원래 꼴 물음에만 남는다.
2. **문장으로 자른다.** 괄호 밖에서 `.` `!` `?` 바로 뒤에 빈칸이 오면 거기서 자른다(괄호 깊이는 4와 같다). 마침표는 앞 토막에 남는다.
   「다 사면」 처럼 「다」 뒤에서는 안 자른다.
3. **이음 기호로 한 번 더 자른다.** 앞뒤를 띄어 쓴 ` · ` ` — ` ` ↔ ` 에서 자른다.
   붙여 쓴 `4·단축` 의 `·` 는 낱말 안이라 안 자른다.
4. **괄호 안은 안 자른다.** `(` `（` `「` 에서 깊이 +1, `)` `）` `」` 에서 −1. 깊이가 0 이하일 때만 3을 한다.
5. **날짜 괄호를 지운다.** 안에 괄호가 없는 `(…)` `（…）` 가운데 날짜 꼴(`YYYY-MM-DD` · 두 자리 `MM-DD` · `M월 D일`)이 든 것을 앞 빈칸째 지운다.
   앞뒤가 숫자면(`110-08`) 날짜가 아니다. `(96분)` `(3-5개)` 는 남는다. 결과 `pieces[].text` 는 지운 글이다.
6. **목록 꼴은 건너뛴다.** `①`~`⑳` 또는 앞이 빈칸인 `1)` 이 2개를 넘게 든 토막은 안 묻고 기록 `skipped` 에 센다. 원래 꼴 답이 덮는다.
7. 앞뒤 빈칸을 다듬고 빈 토막은 버린다. 토막이 하나뿐이어도(이음 기호 없는 근거) 그대로 묻는다 — 실측과 같은 꼴을 지킨다.
8. **상한** : 건너뛰고 남은 토막이 12개를 넘으면 앞 12개만 쓰고 버린 수를 돌려준다.

보기 : `[절 : 3] 칸 4·단축 5단계를 다 사면(사람 판에서 96분) 골드가 고인다. 그 뒤 후보 : 농장(번식 · 상한) · 가판대 강화.`
→ `칸 4·단축 5단계를 다 사면(사람 판에서 96분) 골드가 고인다.` / `그 뒤 후보 : 농장(번식 · 상한)` / `가판대 강화.`

## 3. 합치기 규칙

- 묻는 차례 : 원래 꼴(머리 있는 근거 ↔ 주장) → 토막 1 ↔ 주장 → … 토막 n ↔ 주장. 주장은 모두 같은 글이다.
- 판정 = **b 가 가장 큰 답** 하나의 a·b·c(·d) 묶음. 같은 b 면 먼저 물은 쪽(원래 꼴)이 이긴다.
- 기록(`split`) : `base_b`(원래 꼴 b) · `pieces`(토막마다 `text`·`b`) · `best`(이긴 토막 순번, 0부터 · 원래 꼴이 이기면 −1) · `capped`(상한으로 버린 수, 0 이면 안 씀) · `skipped`(목록 꼴로 안 물은 토막 수, 0 이면 안 씀). 토막이 0개면 `pieces: []` · `best: -1`.
- 경고(b ≥ .8) · 애매(.5 ≤ b < .8) 문턱과 「정리 필요 안 매김」 은 그대로다.

## 4. 물음 수 · 속도

- 물음 수 = 짝마다 1 + 토막 수. 구현 뒤 실측 : 실제 50짝 → 170물음 (3.4배) · 합성 30짝 → 118물음 [실측]. 조사 단계에서 들은 「184물음 · 3.7배」 와 다르다 — 이 수는 자르기 결과(토막 120개)에서 바로 센 값이다.
- 상한 200짝이면 [추정] 약 740물음 · 물음당 0.2초 ≈ 2.5분. 최악(짝마다 13물음) 2600물음은 5분 기다림 상한에 걸려 남은 줄이 Problem 이 된다 — 그때는 `--limit` 을 줄이거나 `--no-split`.
