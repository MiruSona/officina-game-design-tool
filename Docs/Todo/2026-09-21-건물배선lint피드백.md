# stage lint 사용 피드백 — 건물 2채 배선 (2026-09-21)

> 반영 (2026-09-21) : `stage lint --changed`(git 변경분 모으기)와 `--verbose`(돈 검사·건너뛴 까닭 찍기) 둘 다 넣었다.

게임 저장소에서 건물 그림 배선을 끝내고 `stage.exe lint` 를 돌린 기록이다.

```

→ 검사를 마쳤습니다 — 파일 4개, 막을 것은 없습니다. (종료 0)
```

고친 파일은 `BuildingObject.cs` · `LayoutConst.cs` · `FarmViewManager.cs` · `SpriteKeys.cs` 다.

## 잘 된 것

- 1초 안에 끝났고 종료 코드 0 이 바로 보였다.
- 코드 파일만 넘겨도 불평 없이 통과한다. 기획서가 아닌 파일을 섞어도 막지 않는다.

## 아쉬운 것

- **이번 판은 문서도 두 장(`그림요청목록.md` · `진행상황.md`) 같이 고쳤는데**,
  lint 에 넘길 파일을 손으로 골라 적어야 했다.
  `stage lint --changed` 처럼 **git 이 본 변경 파일을 알아서 모아 주는 옵션**이 있으면
  「빠뜨리고 안 걸었다」가 줄겠다.
- 통과했을 때 **무엇을 검사했는지가 안 보인다.** 「파일 4개, 막을 것은 없습니다」뿐이라
  기획 순서 검사가 실제로 돌았는지 코드 파일이라 건너뛴 건지 알 수 없다.
  `--verbose` 로 검사 항목 이름이라도 찍히면 좋겠다.
