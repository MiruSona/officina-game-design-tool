# 전용 화면 판2(판매 화면) lint 피드백

- 날짜 : 2026-10-04
- 쓴 곳 : 게임 저장소, 서브에이전트 한 판 끝에 `stage lint <고친 파일 11개>`

## 잘 된 것

- 파일 11개를 한 번에 넘겨 「막을 것은 없습니다」 와 종료 0 을 바로 받았다. 빨랐다.

## 헷갈린 것

- 통과일 때 어떤 검사를 돌렸는지(기획 순서 · 시스템 문서 짝 등)가 안 보인다.
  새 파일(StallLayout.cs · StallScreenSetup.cs)이 「시스템 문서 없이 코드 쓰기」 검사를 왜 통과했는지 알 수 없었다.
  `-v` 같은 옵션으로 파일마다 돌린 검사 이름을 보여 주면 좋겠다.
